# Cyclistic Bike-Share Analysis | 2019

This project analyzes about 3.8 million bike-share trips from 2019 to understand differences in riding behavior between casual Customers and annual Subscribers.

Using Google BigQuery for SQL, Excel for analysis and some visualizations, and Tableau for further data visualization, I examined ride duration, weekly and monthly ridership trends, and hourly usage patterns.

The goal was to identify behavioral differences between the two membership groups and develop marketing recommendations that could help Cyclistic convert casual riders into annual Subscribers.
